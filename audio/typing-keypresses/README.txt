Typing keypress samples
=======================

Source: “ES_Computers, Keyboard & Mouse, Keyboard, Razer, Typing, Slow - Epidemic Sound.mp3” supplied by Emma Xu.

Six single keypress/return sounds cut from quiet portions of the 71-second recording.
Files: mono 48 kHz PCM WAV. Start and end have 5 ms fades to avoid edit clicks.
keypress-preview.wav plays them in order with a short gap for auditioning.

Source positions:
- keypress-01.wav: 0.973–1.233 s
- keypress-02.wav: 6.101–6.316 s
- keypress-03.wav: 17.405–17.670 s
- keypress-04.wav: 23.721–23.951 s
- keypress-05.wav: 50.884–51.124 s
- keypress-06.wav: 61.525–61.775 s

In the website, trigger one randomly selected sample for each visible character,
skip spaces/newlines, and limit the combined rate if labels type at once.
Set final effect volume in the site so it sits under the music.
